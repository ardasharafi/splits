# Splits for iPhone

The iPhone version of Splits, the payout ledger. Open
<https://ardasharafi.github.io/splits/> on the iPhone, or scan the QR code in
Splits on the computer: Settings, Sync with GitHub, Use Splits on your iPhone.

This repository holds only the app's code. The ledger itself never comes here:
it stays encrypted (AES-256-GCM, unlocked only by your password) in a private
repository, and it is opened only on your own devices.
